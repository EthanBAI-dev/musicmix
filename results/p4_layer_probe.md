# MERT 逐层线性探针：用数据选层

- 基座：`m-a-p/MERT-v1-95M`（13 层 × 768 维）
- 数据：autotagging_top50tags · split-0，train 1290 / val 466 首
- 特征：每层的**时间平均**（丢掉时序），逻辑回归，验证集比 mAP
- 命令：`python -m scripts.probe_layers`

> 这是**层选择**而非最终性能。时间平均丢掉了所有时序信息，
> 绝对数字会低于 L1/L2；但层与层的**相对高低**可信，这正是我们要的。

| 层 | mAP | ROC-AUC |
|---|---|---|
| 0 | 0.1538 | 0.6406 |
| 1 | 0.1568 | 0.6473 |
| 2 | 0.1620 | 0.6678 |
| 3 | 0.1700 | 0.6774 |
| 4 | 0.1683 | 0.6796 |
| 5 | 0.1787 | 0.6925 |
| 6 | 0.1835 | 0.6976 |
| 7 ★ | 0.1915 | 0.7036 |
| 8 | 0.1866 | 0.6956 |
| 9 | 0.1810 | 0.6954 |
| 10 | 0.1697 | 0.6795 |
| 11 | 0.1552 | 0.6653 |
| 12 | 0.1466 | 0.6419 |

## 结论

- **最佳是第 7 层**（mAP 0.1915）
- 末层（第 12 层）mAP 0.1466，比最佳低 **23.4%**
- 最差是第 12 层（mAP 0.1466）

自监督模型的最后几层往往过度特化到预训练任务（掩码 token 预测），
下游任务反而不如中间层 —— 直接用末层是常见但次优的做法。
后续 L1/L2 一律用**第 7 层**。
