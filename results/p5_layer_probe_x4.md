# MERT 逐层线性探针：用数据选层

- 基座：`m-a-p/MERT-v1-95M`（13 层 × 768 维）
- 数据：autotagging_top50tags · split-0，train 3147 / val 1144 首
- 特征：每层的**时间平均**（丢掉时序），逻辑回归，验证集比 mAP
- 命令：`python -m scripts.probe_layers`

> 这是**层选择**而非最终性能。时间平均丢掉了所有时序信息，
> 绝对数字会低于 L1/L2；但层与层的**相对高低**可信，这正是我们要的。

| 层 | mAP | ROC-AUC |
|---|---|---|
| 0 | 0.1776 | 0.6922 |
| 1 | 0.1776 | 0.6954 |
| 2 | 0.1773 | 0.6948 |
| 3 | 0.1815 | 0.7013 |
| 4 | 0.1873 | 0.7059 |
| 5 | 0.1849 | 0.7155 |
| 6 | 0.1955 | 0.7175 |
| 7 ★ | 0.1976 | 0.7195 |
| 8 | 0.1895 | 0.7130 |
| 9 | 0.1800 | 0.7060 |
| 10 | 0.1763 | 0.6977 |
| 11 | 0.1727 | 0.6920 |
| 12 | 0.1740 | 0.6953 |

## 结论

- **最佳是第 7 层**（mAP 0.1976）
- 末层（第 12 层）mAP 0.1740，比最佳低 **12.0%**
- 最差是第 11 层（mAP 0.1727）

自监督模型的最后几层往往过度特化到预训练任务（掩码 token 预测），
下游任务反而不如中间层 —— 直接用末层是常见但次优的做法。
后续 L1/L2 一律用**第 7 层**。
